key → identity of list elements/components during reconciliation.
    - A B C
    - A C D

Reacts identifies using key A C are same and C is removed and D is added, so by comparing 2 DOM trees it updates just new components / changed componenets 

Hook order → identity of Hooks within a component.
Always create hook on top of components
do not create inside loops, if or any conditional codes

React conceptually keeps:

RideCard instance
    Hook #1 → expanded
    Hook #2 → loading

On every render, React expects:

Hook #1 → same Hook
Hook #2 → same Hook

That's why you can't do:

if (something) {
    useState(); // ❌
}

because the Hook order could change between renders.

Login/Signin

    - token which we got from backend is stored in local storage
    - navigate to homepage

when user do booking/cancel we need to share token for auth middleware in backend
this is done using interceptor in axios.js which by default add token in header of each api request


Navbar -> LogIn and LogOut Button which works as toggle
